# Social post mocker

Mock X posts and threads (desktop and mobile), launch emails and Slack messages on an infinite canvas, and export PNGs. One self-contained HTML file with no build step or server.

**Open it:** https://morikyl.github.io/social-post-mocker/

Your work is saved in your browser. To share a canvas, use **Share link**, which uploads it as a secret GitHub gist. Anyone with the link can open an editable copy, with no login. Uploading needs a GitHub token with the `gist` scope, which is kept in your browser only.
